### Grafikui

Design engineering studio in London, building production software end to end from design systems and interface architecture through to PostgreSQL, APIs and deterministic AI workflows.

**[grafikui.com](https://www.grafikui.com)**

---

### Products

- **[Comprent](https://www.comprent.co.uk)**: UK landlord compliance platform for the Renters' Rights Act 2025, with deterministic deadline/ground logic, GOV.UK Form 3A/4A filling, guidance watch and a grounded assistant.
- **[Maddox Engine](https://www.maddoxengine.com)**: Design-system verification for coding agents, pre-commit and CI, with a hosted team dashboard.
- **[BlocInsights](https://www.blocinsights.com)**: Two-sided qualitative research platform turning stakeholder interviews or senior marketer panels into attributed insight reports.
- **[Motion Manifesto](https://motionmanifesto.co.uk)**: Live interactive reference for `@grafikui/motion`.

---

### Open Source

- **[maddox-cli](https://github.com/omrdev1/maddox-cli)**: Design-token, motion and component-state drift scanner (`maddox-engine` on npm), Claude Code `PostToolUse` and git `pre-commit` hooks, and GitHub Action.
- **[greenops-cli](https://github.com/omrdev1/greenops-cli)**: Zero-network Terraform carbon, water and cost linter for AWS, Azure and GCP pull requests.
- **[@grafikui/motion](https://github.com/omrdev1/grafikui-motion)**: Six React motion primitives with separate Framer Motion and GSAP entry points.
- **[Saga Engine](https://github.com/grafikui/saga_engine)**: Crash-resilient PostgreSQL-backed saga orchestration engine for Node.js and TypeScript.
- **[Saga Engine Go](https://github.com/grafikui/saga-engine-go)**: Crash-resilient PostgreSQL-backed saga orchestration engine in Go.
